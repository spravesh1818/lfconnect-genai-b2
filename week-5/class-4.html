Concept 02

Why Graphs Beat One Opaque Loop

  • A single while-loop hides which step is running and what state changed
  • LangGraph makes steps explicit: each node is a function, each edge is a allowed transition
  • You can inspect, log, and test nodes independently — remember vs. recall vs. answer
  • Multi-agent pipelines (researcher, writer, editor) become readable graphs, not nested if-statements

Concept 03

LangGraph Building Blocks

State

TypedDict

Shared fields every node reads and returns — e.g. user_message, notes, reply.

Nodes

Functions

Python callables that take state in and return partial state updates.

Edges

START → END

add_edge wires fixed order; conditional edges branch on state.

Checkpoint

InMemorySaver

compile(checkpointer=...) saves thread state between invokes — same family as Class 3.

Concept 04

Checkpointing vs JSON File Memory

Checkpointer (InMemorySaver)

  • Resumes the same graph run by thread_id
  • Stores messages and intermediate state in memory
  • Gone when the process exits — unless you plug a durable backend

JSON Notes (agent_notes.json)

  • Survives new threads and notebook restarts
  • You choose exactly which facts to persist
  • Human-readable — open the file and audit what the agent "knows"

Part A uses both: checkpointer for the conversation thread, JSON for durable user facts.

Pitfalls & Misconceptions

Where This Breaks

Stale Notes

JSON facts never expire — you need update/delete logic or timestamps.

Invented Research

Writer prompts must forbid filling gaps when the researcher returns a miss.

Unbounded Graphs

Conditional edges without caps can loop forever — set recursion limits.

Confusing Layers

Checkpointer ≠ long-term memory — don't expect InMemorySaver to survive restarts.

Recap

Key Takeaways

  • Short-term = message list in graph state; long-term = explicit JSON notes on disk
  • LangGraph = state + nodes + edges + optional checkpointer
  • Part A proves a fact survives a new thread via agent_notes.json
  • Multi-agent = specialized nodes wired in a readable pipeline
  • Ground writers in research output — never trust the model to invent catalog facts
  • Vectors and RAG arrive in Week 6 — not required for durable memory today
